# Integration checklist

- [ ] Identified existing audio context / sound library owner.
- [ ] No duplicate render loop or physics event system.
- [ ] Actual user gesture unlock and silence/mute policy.
- [ ] Independent Music/SFX/UI levels and no duck override.
- [ ] All started sources end / are stopped and disconnected.
- [ ] Tests passed with relevant environment details.
- [ ] Tested in real browsers and devices (or recorded as not performed).
- [ ] Original resources and unrelated code preserved.
