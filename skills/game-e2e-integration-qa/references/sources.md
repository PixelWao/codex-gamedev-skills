# Official references and limits

Official Playwright: https://playwright.dev/docs/intro and https://playwright.dev/docs/api/class-tracing. Use bundled runner without a network dependency in shipped archive; Playwright/Chromium must be installed separately. A local HTTP server must be run by the host project.
Test hooks should expose read-only snapshots of player state, FPS counters and scene readiness; never bundle production cheats.
