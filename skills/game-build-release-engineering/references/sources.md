# Official references and limits

itch.io HTML5 official rules: https://itch.io/docs/creators/html5 . The ZIP must have index.html at root; files are case-sensitive; default limits include 1000 files, 500MB total and 200MB per file. Site rules may change: verify current docs before final release.
Use game-e2e-integration-qa for actual smoke tests of unpacked output, performance-optimization for frame pacing, and game-ui-accessibility-qa for mobile layout/accessibility.
