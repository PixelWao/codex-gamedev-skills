# Integration playbook

Example: Battle of Keppler map editor — instantiate terrain units as data first, snap tile coordinates, link units, validate reachable objectives, export JSON schema with version. WRECK CREW — author blockout building modules with anchored/support metadata, then validate destruction graph and colliders.
For Three.js import `TransformControls` from `three/addons/controls/TransformControls.js`; attach selection; use `objectChange` to update document; pause orbit controls while dragging; remove helper on dispose.
Distinguish editor schema from runtime save-game schema. Run tests after resizing viewport, changing DPR, undoing deletion of a parent with nested children.
