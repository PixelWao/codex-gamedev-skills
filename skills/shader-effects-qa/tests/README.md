Run `python -m unittest discover -s tests -v`. The tests validate numerical masks and image comparison on deterministic fixtures; they do **not** compile GPU shaders or run a game. Open `tests/browser_compile.html` on a GPU-enabled WebGL2 browser to compile/link the paired fixture, then render the real effect on the target device and compare actual gameplay captures. `compare_images.py` supports PNG with Pillow and PPM P6 without additional dependencies.
